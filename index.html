Простота понад усе

Ядро 1.0 побудовано на трьох принципах: автономність, передбачуваність, розширюваність.

🔋

Автономність

Усі 10 модулів працюють без інтернету. Дані зберігаються локально в браузері.

📐

Передбачуваність

Кожен модуль має стабільний API версії 1.0. Жодних прихованих залежностей.

🧩

Розширюваність

Ядро не залежить від розширень. Розширення підключаються за потреби.

10 модулів · Версія 1.0

Ядро платформи

Кожен модуль — самостійна одиниця зі стабільним API. Модулі не залежать одне від одного, крім явних зв'язків.

01
📦

Product Core

Базові дані товарів: назва, категорія, одиниця виміру, виробник, ціна. Основа для всіх інших модулів.

  • create(data) — додати товар
  • get(id) — отримати товар
  • list(filter) — список товарів
  • update(id, data) — оновити
  • delete(id) — видалити
02
🏭

Batch Manager

Партії товарів: номер, дата виробництва, термін придатності, залишок. Відстеження терміну придатності.

  • createBatch(productId, data)
  • get(id) — партія
  • list(filter) — партії
  • updateRemaining(id, qty)
  • daysUntilExpiry(id)
03
📊

Inventory Engine

Розрахунок залишків на основі партій. Мінімальні запаси, пороги поповнення, автоматичні позначки low-stock.

  • getStock(productId)
  • getAllStock() — всі залишки
  • setMinStock(productId, qty)
  • getLowStock() — дефіцит
04
🗄️

Storage Manager

Локації зберігання: полиця, морозильник, комора. Температурні зони. Закріплення товарів за локаціями.

  • createLocation(data)
  • assign(productId, locationId)
  • getLocation(id)
  • listLocations()
05
📷

Barcode Registry

Реєстр штрихкодів: EAN-13, UPC-A, QR. Локальна база + пошук через OpenFoodFacts API (за наявності інтернету).

  • lookup(code) — знайти товар
  • register(code, productId)
  • scan() — сканувати камерою
  • getByProduct(productId)
06
🎥

Camera AI

Сканування штрихкодів і текстів через камеру. Подвійний рушій: BarcodeDetector API + QuaggaJS. OCR через Tesseract.js.

  • startScan(mode)
  • stopScan()
  • capturePhoto()
  • extractText(image)
07
🍳

Recipe Engine

Рецепти: інгредієнти, кількості, кроки. Підрахунок доступності на основі інвентарю. Чек-лист продуктів.

  • create(data) — рецепт
  • checkAvailability(recipeId)
  • list(filter) — рецепти
  • getShoppingItems(recipeId)
08
🔔

Notification Center

Сповіщення: закінчення терміну, low-stock, нагадування. In-app алерти. Без зовнішніх push-серверів.

  • add(type, message)
  • list(filter) — сповіщення
  • markRead(id)
  • markAllRead()
09
🔒

Security

Ролі: admin, user, viewer. Права доступу на модулі. Локальна автентифікація. Дані користувача не залишають пристрій.

  • login(credentials)
  • can(action) — перевірка права
  • getRole()
  • logout()
10
🔄

Synchronization

Синхронізація між пристроями через localStorage + optional cloud. Офлайн-режим за замовчуванням. Конфлікти вирішуються за timestamp.

  • sync() — запустити
  • getStatus() — статус
  • export() — експорт даних
  • import(data) — імпорт
