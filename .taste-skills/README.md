# Taste-Skills for LifeStock Core

Design taste and visual judgment skills for AI agents working on this project.

## Usage

Point your AI agent (Claude Code, Cursor, Windsurf, Cline, etc.) to this directory.
The agent will check its output against taste principles before shipping.

## Categories

- **perception** — visual audits, detail observation, cross-domain seeing
- **judgment** — design ranking, taste vs trends, tradeoff assessment
- **analysis** — decision tracing, absence audit, version archaeology
- **articulation** — critique vocabulary, design rationale
- **visual-language** — hierarchy, color systems, spatial rhythm, craft signals
- **typography** — type selection, type systems, type as signal
- **interaction** — timing, flow patterns, motion design
- **reference-building** — principle tagging, library architecture
- **team-practice** — design critiques, daily routines, teaching taste
- **evaluation** — self-assessment, quality checklist, field notes
