# Quiz — LifeStock Interactive Learning

Graded questions with ✓/✗ feedback and explanations.

## Construction rules (from amosblomqvist/learn)
1. Every option is a bare claim — no justification in options
2. Write correct claim first, then mutate into distractors
3. Each distractor = a real misconception in the same skeleton
4. No asymmetric bolding
5. If you can tell which is right without knowing the material — regenerate

## Quiz format
- Question text
- 4 even options (same length, same register)
- After answer: ✓/✗ + correct answer + explanation
- Track score across session

## LifeStock quiz topics
- "What does 'use first' sorting mean?"
- "How does the barcode scanner work?"
- "What happens when a product expires?"
- "Why separate Core from AI?"
