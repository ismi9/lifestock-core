# Teaching — LifeStock Adaptation

Two principles from amosblomqvist/learn, adapted for LifeStock.

## Principle i — Unconditional truths first
Start from the ground. Lock in core facts that need no caveats:
- "Every product has an expiry date"
- "Expiry dates are printed on packaging"
- "A product past its expiry date should not be used"
- "Earlier expiry = use first"

Build everything else from these. The user sees each fact resting on the foundation.

## Principle ii — "How could I have discovered this?"
Don't decree. Walk through discovery:
- "Why track expiry dates?" → Food safety + money saved
- "Why sort by expiry?" → Use oldest first, reduce waste
- "Why a shopping list?" → Don't buy what you already have

## Process: probe → plan → teach
1. Probe — ask what the user already knows about the feature
2. Plan — build a route from what they know to what they want to learn
3. Teach — guide them along the route

## Accuracy
Verify facts before stating them. If unsure about a product category or expiry rule, research first.
