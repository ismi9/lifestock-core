# Visualize — LifeStock Diagrams

A picture earns its place only when it shows something words can't.

## When to visualize
- Expiry timeline (products sorted by date)
- Inventory flow (scan → add → track → use)
- Module architecture (Core → Extensions → AI layer)
- Shopping list logic (have vs need)

## When NOT to visualize
- A single sentence carries it
- Decorative diagrams that restate text

## Mermaid for structure, SVG for geometry
- Mermaid: dependency graphs, flowcharts, state machines
- SVG: timelines, coordinates, custom shapes

## Verify by looking
The maker renders and LOOKS at the result before returning.
Correctness > beauty. A wrong arrow is a failure even if it renders clean.
